小智 MCP 管理面板 v2.0
支持多接入点管理、连接测试、本地工具测试、实时日志。

工具集：
· filesystem — 文件读写（/home/user）
· web — 必应搜索 + 网页抓取
· weather — 绵阳实时天气（Open-Meteo）
· system — 系统状态/时间/记事本/执行命令/DeepSeek Harness/密码生成/二维码/单位换算
· dev — JSON/Base64/URL/时间戳/UUID/Hash/正则/DNS/HTTP/端口检测

守护机制：异常兜底、退避重启、刷屏自愈、2小时定期重启
